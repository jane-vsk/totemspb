TOTEM — публикация сайта
=========================

Подготовленная версия основана на totem_site_prototype_v15.html.

Сейчас SEO-адрес в index.html, robots.txt и sitemap.xml временно задан как:
https://jane-vsk.github.io/totem/

Если подключается собственный домен, например https://example.ru/, замените этот адрес в:
- index.html (canonical, og:url, og:image, JSON-LD)
- robots.txt
- sitemap.xml

Структура:
- index.html — сайт
- assets/ — оптимизированные изображения
- robots.txt — разрешает индексацию и указывает sitemap
- sitemap.xml — карта сайта
- site.webmanifest — метаданные сайта

GitHub Pages:
1. Создать публичный репозиторий `totem` в аккаунте jane-vsk.
2. Загрузить ВСЁ содержимое этой папки в корень репозитория (не саму папку целиком).
3. Settings → Pages → Deploy from a branch → main / root → Save.
4. Временный адрес будет https://jane-vsk.github.io/totem/

Для Яндекс Вебмастера потребуется собственный домен. После покупки домена подключите его в Settings → Pages → Custom domain, затем обновите SEO-адреса выше.


Юридический блок:
- privacy.html — Политика обработки персональных данных.
- Оператор: Тимофеев Никита Евгеньевич, самозанятый.
- Контакт: Criterion@list.ru.
- В index.html добавлена cookie-плашка и ссылка на Политику.
- Яндекс Метрика по умолчанию НЕ загружается. После создания счётчика найдите:
  var COUNTER=0;
  и замените 0 на номер счётчика. Метрика будет подключаться только после согласия посетителя на аналитику.
